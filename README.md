# mcp-giphy

Giphy MCP — wraps Giphy API (public beta key, free)

Part of the [Pipeworx](https://pipeworx.io) open MCP gateway.

## Tools

| Tool | Description |
|------|-------------|

## Quick Start

Add to your MCP client config:

```json
{
  "mcpServers": {
    "giphy": {
      "url": "https://gateway.pipeworx.io/giphy/mcp"
    }
  }
}
```

Or use the CLI:

```bash
npx pipeworx use giphy
```
